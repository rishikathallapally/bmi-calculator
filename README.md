# BMI Calculator 🌿

A simple and responsive BMI Calculator built using React and Tailwind CSS.

## Live Demo 

[Click Here](https://rishikathallapally.github.io/bmi-calculator/)

## Features

- Calculate BMI using weight and height.
- Display BMI value and category.
- Four BMI categories: Underweight, Normal Weight, Overweight and Obese.
- Input validation.
- Reset functionality.
- Responsive design for mobile and desktop.
- Elegant Sage Green theme.

## Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- HTML
- CSS
- Vite

## Installation and Setup

1. Clone the repository.
2. Navigate to the project folder.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

## BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9 | Overweight |
| 30 or above | Obese |

## Disclaimer

This calculator is intended for adults aged 18 and above. BMI is a screening tool and not a medical diagnosis.
